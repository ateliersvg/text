# Logo

A serif capital T, drawn as a contour rather than as strokes, sitting on the baseline the
package computes. The letterform is the emblem because the package turns Unicode into
positioned glyph outlines: the mark is an instance of what it makes.

| File | Box | Contents |
| --- | --- | --- |
| `mark.svg` | 24 x 24 | the letter in the package accent, with its baseline |
| `mark-mono.svg` | 24 x 24 | the same contour in `currentColor`, single weight |

Accent `#e8657f`, soft `#f2a0b1`. `mark-mono.svg` takes the colour of its context, which is
what a README or a sidebar needs.

The full `ATELIER \ TEXT` lockups do not exist yet: the other packages derive theirs from the
Atelier wordmark, which is type converted to paths and is not reproduced here.
