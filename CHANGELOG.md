# Changelog

Public API and behaviour changes only. Versions follow Semantic Versioning.

## 0.8.0 - 2026-08-15

### Added

- Unicode codepoints mapped to positioned glyphs and vector outlines
- Combined SVG path data, or a complete `atelier/svg` document
- Fonts loaded directly or through `Alto\Font\FontFinder`
- Letter spacing, word spacing, and collision-safe SVG IDs
- Typed exceptions for invalid text arguments and missing glyphs
