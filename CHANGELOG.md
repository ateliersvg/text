# CHANGELOG

## 0.8.0 - 2026-08-15

Initial release.

- Map Unicode codepoints to positioned font glyphs and vector outlines.
- Render combined SVG path data or complete `atelier/svg` documents.
- Load fonts directly or through `Alto\Font\FontFinder`.
- Support letter spacing, word spacing, and optional collision-safe SVG IDs.
- Report invalid text arguments and missing glyphs through package exceptions.
